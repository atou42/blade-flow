# Reference Games

## Core Combat References

[One Step From Eden](https://store.steampowered.com/app/960690/One_Step_From_Eden/) is the closest reference for real-time action plus deckbuilding. The lesson is useful in both directions. It proves that real-time card play can work, but it also shows the risk of overwhelming players who need to read cards while dodging.

[Duelists of Eden](https://www.duelistsofeden.com/) is useful for thinking of cards as fighting-game moves instead of turn-based commands.

[Fights in Tight Spaces](https://store.steampowered.com/app/1265820/Fights_in_Tight_Spaces/) is useful for card-as-action presentation. It is slower than this project, but its physical move readability is valuable.

[Devil May Cry 5](https://store.steampowered.com/app/601150/DEVIL_MAY_CRY_5__/) is the emotional reference for combo style, route expression, and the feeling of winning beautifully.

[Balatro](https://store.steampowered.com/app/2379780/Balatro/) is the reference for visible chaining, escalating feedback, and small rules creating explosive results.

## Roguelike References

[Slay the Spire](https://store.steampowered.com/app/646570/Slay_the_Spire/) is the reference for path risk, compact reward choices, removal, relics, and run identity.

[Hades](https://store.steampowered.com/app/1145360/Hades/) is the reference for keeping the action base stable while boons and keepsakes change the run flavor.

[Dead Cells](https://store.steampowered.com/app/588650/Dead_Cells/) is the reference for weapon identity, gear feel, and unlockable content pools.

[Risk of Rain 2](https://store.steampowered.com/app/632360/Risk_of_Rain_2/) is the reference for stacking items that can become wild while still being readable.

[Vampire Survivors](https://store.steampowered.com/app/1794680/Vampire_Survivors/) is the reference for simple upgrades, evolutions, and immediate power fantasy.

[The Binding of Isaac: Rebirth](https://store.steampowered.com/app/250900/The_Binding_) is the reference for strange passive items and memorable run mutations.

[Monster Train](https://store.steampowered.com/app/1102190/Monster_Train/) is the reference for main and secondary archetype mixing.

[Luck be a Landlord](https://store.steampowered.com/app/1404850/Luck_be_a_Landlord/) is the reference for compact synergies that remain legible.

## System References

[Dead Cells Gear](https://deadcells.wiki.gg/wiki/Gear) and [Dead Cells Affixes](https://deadcells.wiki.gg/wiki/Affixes) are useful for equipment variety, but this project should avoid random stat affix bloat.

[Hades Keepsakes](https://hades.fandom.com/wiki/Keepsakes) are useful for pre-run identity and reward steering.

[Risk of Rain 2 Items](https://riskofrain2.wiki.gg/wiki/Items) and [Risk of Rain 2 Equipment](https://riskofrain2.wiki.gg/wiki/Equipment) are useful for passive stacking and strong active-equipment identity.

[Slay the Spire Transform](https://slaythespire.wiki.gg/wiki/Transform) is useful for card conversion and deck-shaping choices.

[Backpack Hero Relics](https://backpackhero.wiki.gg/wiki/Relics) are useful for equipment-driven build identity.
