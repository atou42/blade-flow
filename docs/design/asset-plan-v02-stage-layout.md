# Asset Plan v0.2: Stage Layout Direction

Date: 2026-05-07

Selected reference: `assets/generated/v0.2/bf-v02-duel-stage-layout_001.png`.

This direction should become the visual anchor for the next Blade Flow asset pass. It is cleaner than the first duel board, keeps the player/Boss vertical relation readable, and leaves enough combat space for cards, slashes, health feedback, and boss attacks.

## Production Targets

Generate four boards from this reference direction:

- Player combat asset board: readable player silhouette, idle pose, lunge pose, hit pose, sword glow.
- Boss combat asset board: readable Boss silhouette, red core, idle pose, attack pose, damaged pose.
- Combat arena background: clean vertical stage without characters, with enough pale center space for gameplay.
- Boss pressure VFX board: red core beam, downward strike, warning halo, player hit impact.

## Acceptance Criteria

All generated images must preserve the selected direction: pale ink stage, vertical duel spacing, clean negative space, controlled red/black marks, and small green player blade accent. The outputs must not return to the dirty first-pass look. Character boards can be painterly, but silhouettes must be separable enough to later crop into playable assets.
