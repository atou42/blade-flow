# 风格统一 Spec

日期：2026-05-07

这份文档定义 Blade Flow 后续 Boss、怪物、装备、遗物、契约、地图、卡牌和 UI 的统一风格。目标是让所有新增资产都属于同一个世界，而不是各自好看但拼在一起变脏。

## 总体方向

Blade Flow 的统一风格是国画纸面上的水墨刀光。画面底色是骨白和浅灰宣纸，主体是黑墨剪影，危险和 Boss 核心用朱红，玩家速度和追击用少量荧绿，闪反用紫，爆发用金。所有颜色都必须有功能含义，不能为了装饰乱加。

画面应该干净、留白、锋利。角色可以有墨迹和破碎边缘，但不能脏成一团。玩家、Boss、敌人、卡牌、地图和弹窗都要共享纸纹、墨边、印章和刀痕语言。

## 色彩规则

骨白负责纸面、角色衣摆、可读 UI 底。黑墨负责身体重量、边框、阴影和敌人轮廓。朱红负责 Boss 核心、危险、受击和死亡。荧绿只给玩家追击、速度和连击活性。青色只给挑空、上升和浮空。紫色只给闪反、镜面、残影和假动作。金色只给爆发、破势、处决和重击。红色只给压制、流血、危险和 Boss 攻击。

同一个资产最多使用一个路线主色加黑墨、骨白、朱红点缀。装备、遗物、契约和节点都要遵守这个限制。否则手机屏幕会变成彩色噪音。

## 形状规则

追击用箭痕、前冲刀线、尖锐斜角。挑空用上升刃、竖向飞白、悬停墨痕。闪反用回旋弧、碎镜、残影圈。爆发用重印、断头台方块、厚重下压。压制用裂口、血线、细长锐角。

Boss 的形状要上重下轻，悬在上方有压迫感。普通敌人要小一号，动作更单一，不能像 Boss 一样复杂。装备图标要像战斗身份，不像背包物品。遗物图标要像器物剪影。契约图标必须带黑色裂纹。战斗证据要像从 Boss 身上拆下来的碎片。

## 角色和 Boss 统一规则

玩家形象保持骨白衣摆、黑墨身体、红色飘带和绿色刀光。玩家不能因为换装备变成完全不同角色，只能通过刀光、徽记、卡牌边框和少量姿态差异表达装备身份。

Boss 必须有红色核心。每个 Boss 的轮廓、武器和抬手动作要不同。风暴队长是细长雷刃和破旗，镜拳是镜面臂甲和紫色残影，盾卫是大盾和低重心，红线宿敌是红线披帛和玩家镜像姿态。Boss 升级或路线烙印时，优先改核心亮度、武器姿态、肩背轮廓和抬手动作，不只改血条或名字。

普通敌人要遵守教学单一性。刀信使教快刀追击，铃盾卒教破势下划，灰羽弓手教距离补牌，镜侍教假动作，鼓槌力士教慢刀贪刀。每个普通敌人的动作资产只围绕一个战斗问题设计。

## UI 统一规则

UI 使用宣纸底、墨边、印章、半透明纸层和短阴影。文字必须比背景更清楚。功能性优先于水墨氛围，任何看不清的纸纹、叠图、低对比字都必须让位给可读性。

卡牌保留国画卡面和等级差异，但卡牌上的动作信息要比装饰更靠前。卡牌必须同时展示路线色、动作图标、方向提示和等级。文字只用于确认，不承担主要理解。

调配器、版本日志、武器选择、奖励选择和结算都要使用同一套纸层和印章按钮。不能战斗页是国画，调配器又变成现代面板。

## 地图和奖励统一规则

上行刀路地图是竖向刀痕。稳路用浅墨和骨白边，险路用路线色和黑裂纹边。节点用印章表示，普通战是小刀口，精英是双刀口，商店是钱纹印，锻造是锤印，侦察是眼印，事件是裂印，Boss 预演是影印，最终 Boss 是大红核心印。

奖励卡不能只靠标题区分。装备奖励看武器姿态，遗物奖励看器物剪影，契约奖励看黑裂纹，战斗证据奖励看 Boss 碎片。稀有度可以影响纸张、边框和印泥浓度，但不能覆盖路线颜色。

## 特效统一规则

刀光是墨痕加亮刃，不是干净霓虹线。命中用墨爆和短暂停顿。破势用金色重印和 Boss 轮廓塌陷。闪反用紫色残影和反向刀弧。追击用绿色前冲线和补牌脉冲。Boss 攻击用朱红核心、抬手剪影和下压墨痕。

结算动画使用水墨斩字。打完 Boss 后先让最后一刀动画打出去，再出现斩字、Boss 碎裂和奖励，不允许先结算再补动画。

## 资产验收

任何新增资产进入实现前，必须同时通过四个检查。第一，在 390 像素宽手机视口里能看清轮廓。第二，不读文字也能判断它属于追击、挑空、闪反、爆发还是压制。第三，和现有国画 UI 放在一起不脏、不跳、不抢主要战斗信息。第四，功能状态能被看出来，例如 Boss 快刀、慢刀、假动作、破势、玩家受击和装备身份。

如果一个资产很好看但让玩家更难判断，它不能进入首版。Blade Flow 的美术优先级是读得懂，然后才是帅。
