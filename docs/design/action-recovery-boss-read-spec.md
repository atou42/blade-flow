# Action Recovery And Boss Read Spec

日期：2026-05-10

本文定义下一阶段玩法改动：动作后摇、左划三结果、Boss 读招矩阵、错读反馈和第一批成长属性。目标是把 Blade Flow 从“等进度条然后左划”推进到“看 Boss、听确认点、选择正确招式，并承担出手后摇”。

这份 spec 只定义下一版可落地切片，不重写完整肉鸽结构。音效素材需求见 `docs/design/action-recovery-audio-spec.md`。

## 目标

当前问题是左划收益太稳定。只要玩家等 Boss 进度接近攻击，防御类出招几乎都能形成完美闪反，重置 Boss、降压、保连，还没有明显出手代价。结果玩家学到的是固定套路，不是动作判断。

下一阶段的目标不是让 Boss 单纯更快、更痛或更肉。难度要来自正确选择和出手承诺。玩家读对时要更爽，读错时要立刻知道错在哪里。

完成后，玩家应该能在 30 秒内感到三件事：左划不再万能，重招不能乱交，Boss 每种读招有不同答案。

## 设计原则

左划保持高收益，但收益只在真确认窗口成立。普通左划是侧退或保命，不完整打断 Boss。提前左划、被假抬手骗、Boss 没有真攻击时左划，都会进入空闪或破绽。

后摇是动作承诺，不是 UI 冷却。玩家不是在等冷却条，而是在等角色收招。轻招收招短，重招收招长，读对可以取消后摇，读错会加长后摇。

Boss 提示不能变得含糊。提升难度时，必须给清楚的预备、确认、命中、收招四段。玩家失败后应该能判断是早了、晚了，还是选错招。

进度条降权，但不突然消失。第一幕仍可保留较完整提示，第二幕开始弱化精确进度，转为危险段、Boss 动作、徽记、音效和卡牌短亮。

## 下一版范围

下一版优先做四件事：动作后摇、左划三结果、Boss 读招矩阵、战斗反馈文案和声音触发。气口资源、结构化反制、训练课三段式可以先留接口，不要求一次做满。

默认验证对象是一幕普通战、镜侍精英和风暴队长。只要这三类战斗能证明左划不再万能，就算切片成立。

## 动作后摇

每次出牌后，玩家进入短收招。收招期间不能立刻再出牌。为了避免触控感觉坏掉，收招末尾 160ms 内允许缓存一次输入；缓存输入会在收招结束后立即执行。如果玩家在长后摇前段狂滑，输入不排队，只给一次轻微无效反馈。

基础后摇默认值如下。

| 动作 | 默认后摇 | 说明 |
| --- | ---: | --- |
| 点击轻招 | 180ms | 保持动作卡牌的流动感 |
| 右划追击 | 220ms | 命中后顺，空追可加长 |
| 上划挑空 | 260ms | 换安全时间，不能无限拖 Boss |
| 普通左划 | 340ms | 侧退保命，不完整打断 |
| 完美左划 | 160ms | 读中真确认，强打断并快速恢复 |
| 空左划 | 520ms | 被假抬手骗或无真招时提前左划 |
| 下划重招命中 | 420ms | 高承诺动作 |
| 下划空挥 | 620ms | 错过破势或处决窗口 |
| 妙手取消 | 120ms 到 180ms | 由正确读招、破势、截后撤触发 |

后摇值受难度、装备和奖励影响，但不能被成长完全抹平。尤其是空左划和下划空挥必须保留明显代价。

## 出牌结果

战斗结果分为四类。

稳手是普通正确出牌。它造成基础效果、保连、推进少量补牌，但不改变 Boss 状态。

妙手是卡牌、方向、Boss 窗口和上一拍关系都对上。它能打断、截击、破势、取消后摇、推进补牌，并给更高奖励权重。

空手是出招没有吃到窗口。它有低收益或弱伤害，后摇略长，不触发路线热度。

破绽是明显错读。提前左划被假抬手骗、下划空挥、右划撞后撤横切，都属于破绽。破绽会加长后摇、增加 Boss 压力，严重时断连或被抢招。

左划必须单独拆成普通左划、完美左划、空左划。普通左划不等于失败，它可以保命、换位、保一点连击。完美左划才是打断和反击。空左划必须让玩家听到和看到亏了。

## Boss 时间轴

每个 Boss 动作拆成预备、确认、命中、收招四段。

预备负责告诉玩家有事要发生，但不代表现在可以高收益反击。

确认是正确反应窗口。完美左划、下划破势、右划截后撤等高收益只在确认段或特定收招段成立。

命中是已经太晚。玩家此时再交左划不该打断 Boss，只能吃伤害、擦伤或进入低收益防御。

收招是追击或兑现窗口。后撤横切空挥后，右划收益最高；慢刀砸空后，下划破势或轻招续压收益更高。

## Boss 读招矩阵

| Boss 动作 | 正确高收益答案 | 低收益可用答案 | 错误答案 | 学习反馈 |
| --- | --- | --- | --- | --- |
| 快刀 | 真确认左划或格挡 | 提前轻招压血 | 过晚左划 | “晚了，快刀已经贴身” |
| 慢刀 | 中后段下划破势，上划拖延 | 左划侧退保命 | 把左划当打断 | “慢刀不能被普通侧退打断” |
| 假抬手 | 等第二次真确认左划 | 轻招保守过渡 | 第一次红核就左划 | “假抬手骗出空闪” |
| 后撤横切 | 收招段右划追身 | 等它空挥后轻招 | 提前右划追 | “追早了，撞上横切” |
| 地裂抓取 | 早段上划离地，早段下划破势 | 左划脱离一部分伤害 | 站桩下划处决 | “地裂抓住重招后摇” |

这张矩阵是下一版的战斗核心。它让每个方向都有价值，也让每个方向都有边界。

## 进度条和提示

第一幕普通战可以继续显示完整进度条，帮助玩家建立 Boss 会出手的概念。

精英和 Boss 战开始降低进度条精度。条可以变成危险段，不再是准确倒计时。Boss 动作、读招徽记、真确认闪光和音效承担主要判断。

确认窗口只短亮一到两张相关卡。不能四张一起亮。当前 Boss 窗口对应卡优先，定锚核心卡其次，连段下一拍再次。

错读反馈要写具体原因。不要只写“错读”。文本应该区分“早了”“晚了”“这招不能用左划打断”“重招被抓后摇”。

## 成长属性

后摇可以成为成长属性，但必须按动作关系成长，不做全局攻速。

追击成长缩短右划命中后的后摇，增强右划截后撤的取消收益。它不缩短右划撞横切的破绽。

闪反成长缩短完美左划后的后摇，提高读中后的接招收益。它不大幅缩短空左划，否则左划会重新变成万能保险。

爆发成长缩短下划命中破势后的后摇，提高下划兑现收益。它不缩短下划空挥。

控制成长让上划命中后制造短安全窗，允许下一张轻招更快接上。它不应该让上划无限拖延 Boss。

泛用成长可以略微缩短轻招后摇，但上限要低。全局后摇缩短不应超过 12% 到 18%，避免所有动作重新变成无承诺。

## 气口预留

气口是后续扩展，不进入下一版主实现。它可以理解为高承诺动作的节奏资源。轻招占用少，左划和下划占用多，读对返还，错读锁一小段手牌位。

下一版只需要给数据结构留口径：每个动作结果能报告 `recoveryMs`、`resultType`、`commitmentLevel`。以后要加气口时，不需要重写出牌判断。

## 结构化反制预留

Boss 后续可以记录玩家方向倾向。连续左划多，Boss 提高假抬手或慢刀权重；连续右划多，Boss 提高后撤横切权重；连续下划多，Boss 提高地裂抓取或快刀权重。

下一版不要求完整反制 AI，只要求每次出牌记录最近 5 次方向和结果，调试接口能读到。真正使用这些数据可以放到后续版本。

## 音频和视觉反馈

声音需求按 `docs/design/action-recovery-audio-spec.md` 执行。关键声音是普通左划、完美左划、空左划、后摇取消、后摇拖尾、Boss 真确认、假抬手诱骗和 Boss 看穿。

视觉反馈保持克制。完美左划给紫色反震、Boss 小硬直、卡牌方向箭头短亮。空左划给角色后撤残影断掉、卡牌短暗、Boss 压迫推进。重招空挥给重刃拖尾落空，不给破势爆点。

后摇期间手牌不能像禁用按钮一样死灰。应该是轻压住、稍暗、保留可读性。收招末尾可缓存输入时，手牌边缘可以回亮一点，让玩家知道快能接了。

## 调试与验收

调试接口需要能读到当前后摇剩余时间、上一次出牌结果、上一次后摇来源、Boss 当前阶段、Boss 当前动作、是否处于真确认窗口、最近 5 次方向。

验收一：在快刀真确认窗口左划，Boss 被打断，左划后摇使用完美值，日志显示完美闪反。

验收二：在假抬手第一次红核左划，不打断 Boss，触发空左划，后摇大于普通左划，日志显示假抬手骗出空闪。

验收三：慢刀期间普通左划只能侧退或减伤，不完整重置 Boss。下划在中后段破势才打断慢刀。

验收四：连续左划压测不能稳定打断所有 Boss 动作。至少慢刀、假抬手、地裂抓取会给不同结果。

验收五：收招末尾 160ms 内输入能被缓存并执行，玩家不会觉得触控丢失。收招前段多次输入不会排成长队。

验收六：手机视口下后摇视觉不遮挡手牌文字，新增音效仍然在开战前预解码，手势期间 `resourceCount=0`、`longTasks=0`、`lastError=""`。

## 不做范围

下一版不做完整气口条，不做全局攻速成长，不重做奖励池，不新增大量 Boss，不把进度条完全移除，不做每张牌独立动作帧。

下一版也不削掉左划爽点。目标是让左划从免费保险变成读对才爆赚的招架动作。
