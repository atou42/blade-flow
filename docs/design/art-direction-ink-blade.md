# Art Direction: Ink Blade

Blade Flow 的第一套美术资产走水墨刀光方向。画面应该像一场竖屏日式动作决斗：玩家在下，Boss 在上，双方不是静态 UI 图标，而是可以被刀光、突进和受击带动的剪影。

## Visual Thesis

主视觉用骨白、黑墨、朱红和少量荧绿。骨白负责刀刃和玩家轮廓，黑墨负责身体重量，朱红负责 Boss、危险和受击，荧绿保留玩家连击的速度感。画面不追求写实角色立绘，先追求一眼能读出我、Boss、刀、命中点。

## Asset Rules

玩家资产必须比旧几何人形更像持刀者，但不能占满战斗场。Boss 资产必须在上方形成压迫感，并且有明确的红色核心。刀光资产不做成干净霓虹线，而是用墨痕、飞溅和亮刃叠在一起，让每一次出牌都像斩击，不只是按钮反馈。

## Current Assets

`assets/ink-player.svg` 是玩家剪影，骨白衣摆、黑墨身体、红色 scarf 和绿白刀痕。

`assets/ink-boss.svg` 是 Boss 剪影，黑红外形、鬼面核心和横向刀刃。

`assets/ink-splatter.svg` 是命中墨迹，可用于受击、重斩、破绽和后续 UI 转场。
