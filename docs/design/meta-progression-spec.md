# 长期局外成长 Spec

日期：2026-05-08

这份 spec 定义 Blade Flow 的长期成长体系。目标是让玩家长期有账号成长、解锁、积累和回流动力，但不靠永久攻击力、永久血量或永久冷却把战斗判断压扁。

## 主方向

局外成长的主方案是工坊配方库 + 武器学派树 + 上行图谱。

工坊配方库是系统主轴。玩家用 Boss 证据、路线材料和战斗表现解锁招式配方。配方解锁后进入本局奖励池、锻造池和定锚候选池，但不会开局直接生效。玩家仍然要在本局通过奖励、锻造和战斗窗口把它练成核心。

武器学派树是玩家看到的长期外壳。玩家不是只看到一串配方，而是在练风暴太刀、镜扇、处刑者这些武器。每把武器有自己的学派节点，打开新起势、新定锚候选、新桥接配方、新契约、新遗物入池和训练课题。

上行图谱负责更多关卡和高危路线。主线推进不能被材料卡住。第一幕通关直接打开第二幕基础线，第二幕通关直接打开第三幕基础线。材料和证据只打开高危支线、支线 Boss、高阶契约、稀有配方和每日主题。

## 成长原则

局外成长解锁选择，不解锁纯强度。禁止永久攻击力、永久防御、永久血量、永久补牌冷却和开局好牌。允许解锁新卡牌方向配方、新奖励候选、新武器起势、新训练、新契约、新地图路线、新 Boss 研究和外观证明。

证据是材料，不是成就。后撤截击证据可以用于解锁 Chase Cut 右划截后撤配方。真招读破证据可以用于解锁 Guard 左划镜返配方。裂盾处刑证据可以用于解锁 Breaker 下划碎甲配方或 Execute 下划处决配方。

本局定锚仍然决定当局强度。局外配方只让某个选项有资格出现。本局没有拿到定锚、没有打出窗口、没有完成构筑，这条配方就不会白给强度。

长期成长要让玩家更会构筑，而不是更能碾压。老玩家的优势是选择更多、目标更清楚、路线更危险、构筑更稳定。新玩家的第一局不能像残缺版。

## 工坊配方库

配方是长期成长的核心资产。每个配方都绑定一张卡、一个方向、一个窗口、一个收益和一个失败反馈。

示例配方如下。

| 配方 | 解锁材料 | 入池位置 | 局内效果 |
| --- | --- | --- | --- |
| Chase Cut 右划·截后撤 | 后撤截击证据 | 风暴太刀定锚候选、锻造池 | Boss 后撤确认时右划命中，补牌推进并压回 Boss |
| Guard 左划·镜返 | 真招读破证据 | 镜扇定锚候选、锻造池 | 等第二次真核亮后左划，残影反打并提轻刀 |
| Breaker 下划·碎甲 | 裂盾处刑证据 | 处刑者定锚候选、锻造池 | 金裂或慢刀蓄势中后段下划，破势并推近 Execute |
| Quick Slash 右划·垫追 | 追击路线材料 | 风暴太刀接招池 | Chase Cut 命中后一拍内右划，维持追击势并推近 Thrust |
| Shadow Step 左划·绕身 | 闪反路线材料 | 镜扇接招池 | 真招经过身前时左划，错身后推近 Spin Cut |
| Heavy Cleave 下划·裂印 | 爆发路线材料 | 处刑者接招池 | Breaker 破势后一拍内下划，加深裂纹 |

配方解锁后只进入候选池。它不是永久技能。玩家仍然要在一局中通过奖励、锻造或定锚拿到它。

## 材料和成本曲线

首版只使用三种材料，避免局外背包复杂化。

刀谱墨是通用材料。每局都会给一点，表现越好越多。它用于武器学派树的基础节点和通用配方解锁。玩家即使没有打出特定 Boss 证据，也能感觉长期进度在推进。

Boss 证据是特定材料。后撤截击、真招读破、裂盾处刑都属于 Boss 证据。它用于解锁具体招式配方。例如 Chase Cut 右划截后撤配方必须需要后撤截击证据，不能只靠通用材料购买。

高危印是高风险材料。精英、高危支线和契约战给高危印。它用于解锁契约、高阶路线和稀有配方。高阶内容来自更危险的玩法，不来自刷普通关。

成本曲线保持浅。第一层节点默认开放。第二层节点需要 1 个对应 Boss 证据和少量刀谱墨。第三层节点需要 2 个对应证据和中量刀谱墨。高危契约和高阶路线才需要高危印。

首次打对必须有明显推进。玩家第一次用 Chase Cut 截住后撤，就应该拿到后撤截击证据，并足够打开一个相关入口。基础玩法不能要求重复刷。重复打得更好可以给精通、稀有候选、高危印或评价章。

同一局同一种普通证据最多记一次主奖励。重复打得好可以提高评价和给少量刀谱墨，但不能无限刷材料。Boss 战结算领取绑定 runId，防止读档反复领奖。

## 武器学派树

每把首版武器先做 6 个节点。每个节点只解锁玩法入口。

风暴太刀节点围绕追击。初始节点是 Chase Cut 右划基础定锚。后续节点解锁 Thrust 右划续压、Quick Slash 右划垫追、Flying Blade 右划远距追击、追击契约、追击遗物入池。

镜扇节点围绕闪反。初始节点是 Guard 左划基础定锚。后续节点解锁 Shadow Step 左划绕身、Spin Cut 左划残影补刀、Quick Slash 点击借势轻刀、闪反契约、闪反遗物入池。

处刑者节点围绕破势处决。初始节点是 Breaker 下划基础定锚。后续节点解锁 Heavy Cleave 下划裂印、Execute 下划处决兑现、Launcher 上划崩肩挑、爆发契约、处刑遗物入池。

学派树不能要求玩家重复刷同一关。基础节点随武器默认开放。高级节点通过 Boss 材料、路线材料和高危支线打开。

## 上行图谱

上行图谱是长期内容解锁。主线按通关开，不按材料卡。

第一幕通关后打开第二幕基础线。第二幕基础线至少有镜廊和盾城两个入口。镜廊教假动作和闪反，盾城教霸体和破势。第二幕任意一条基础线通关后打开第三幕基础线。第三幕进入红线宿敌和终局 Boss。

证据只打开更危险和更细的路线。风暴队长后撤证据打开追击猎杀线。真招读破证据打开镜廊高危线。裂盾处刑证据打开盾城精英线。红线证据打开反习惯高危线。

训练馆和每日刀路挂在上行图谱下面。训练馆按 Boss 和招式解锁。每日刀路从已开放区域生成固定种子短局，不吃永久数值，只比连击、妙手率、破绽次数、定锚兑现和收尾质量。

## Profile 和存档

真实 profile 只保存局外解锁。内容包括 Boss 证据、图鉴、训练课、已开放定锚候选、配方库、上行图谱进度、每日纪录和名刀记忆。真实 profile 不保存永久战斗数值。

当前局仍然是 run snapshot，沿用 5 个本地进度槽。run snapshot 保存当前房间、武器、手牌、补牌、奖励、Boss 烙印、当前定锚、调配器参数和弹窗阶段。本局定锚只活在这一局里。

调试 profile 单独分仓，也有 5 个槽。它可以一键全解锁、固定 seed、开指定证据、开指定训练、复制当前局复测。调试 profile 永远不写入真实 profile。界面必须持续标明调试状态。

坏数据继续 fail-close。槽坏了只锁这个槽，不清空、不覆盖。profile 坏了就锁这个 profile，不拿默认空档假装正常。当前局引用不存在的配方或路线档案时，这个槽不能读取，要显示原因。

重复读档不能反复刷局外奖励。每局需要 runId，真实 profile 记录已领取结算的 runId。

## 首版范围

首版只验证风暴队长三条证据线和三把武器的第一层学派。

后撤截击线解锁 Chase Cut 右划截后撤配方、一个追击训练、一个追击定锚候选、一个追击评价章。

真招读破线解锁 Guard 左划镜返配方、一个闪反训练、一个闪反定锚候选、一个闪反评价章。

裂盾处刑线解锁 Breaker 下划碎甲配方、一个爆发训练、一个爆发定锚候选、一个爆发评价章。

三把武器各开放 3 个首版节点。第一个节点默认开放，第二和第三个节点由风暴队长材料打开。这个范围足够验证长期成长是否能和本局定锚咬住。

## 实施优先级

长期局外成长分四步做，不一次性做完整菜单。

第一步做 profile 和材料账本。真实 profile 和调试 profile 分仓。真实 profile 记录刀谱墨、三种 Boss 证据、已解锁配方、已领取 runId。调试 profile 可以一键全解锁、固定 seed、开指定证据，但不能写入真实进度。结算时能拿到刀谱墨和三种证据，读档不能重复领取。

第二步做最小工坊。只做三个配方解锁：Chase Cut 右划截后撤、Guard 左划镜返、Breaker 下划碎甲。玩家花材料解锁后，这些配方进入后续局的定锚候选或锻造池。这里验证解锁不是永久变强，而是以后能见到新选择。

第三步做武器学派树。三把武器各开放三个节点。第一个默认开放，第二和第三个用风暴队长材料打开。界面上玩家看到的是风暴太刀、镜扇、处刑者在成长，不是材料表在增长。

第四步做上行图谱和训练。第一幕通关打开第二幕基础线。三种证据各打开一个训练和一个高危节点。每日挑战、契约和高危印可以放到后续版本，不抢首版验证。

首版验收标准如下。打一局后真实 profile 真的增加材料。同一个 runId 不能重复领取局外奖励。解锁配方后，新局能在奖励或锻造里看到它。没有在本局定锚到对应卡向时，配方不会白给强度。真实 profile 和调试 profile 不互相污染。

## 参考原则

本系统借鉴的是解锁选择和解锁池，不借鉴永久数值碾压。Hades 的武器、热度和契约说明高风险规则可以成为长期目标。Dead Cells 的蓝图说明配方入池能提供长期追求。Into the Breach 和 FTL 的队伍或飞船解锁说明开局选择可以提供长期成长。Slay the Spire 和 Balatro 的卡牌、遗物、牌组和难度解锁说明扩池和起手差异能延长寿命。Rogue Legacy 的庄园式数值成长只作为反例参考，Blade Flow 不把永久属性作为主轴。
