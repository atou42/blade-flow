# Starter Deck

## Deck Direction

The first starter deck uses the blade-dance direction.

It should feel like a light weapon style translated into cards. The cards are actions first and card objects second.

## Cards

| Card | Basic action | Main role |
| --- | --- | --- |
| Quick Slash | Fast close hit | Keeps combo moving |
| Thrust | Forward stab | Starts pressure and closes distance |
| Launcher | Upward strike | Starts air and control routes |
| Chase Cut | Forward chase attack | Continues pressure |
| Spin Cut | Circular slash | Stabilizes awkward hands |
| Shadow Step | Quick evade | Dodges pressure while preserving combo |
| Guard | Short defense | Converts danger into counter chances |
| Breaker | Guard-breaking strike | Opens enemies |
| Flying Blade | Ranged cut | Keeps combo alive at distance |
| Heavy Cleave | Heavy hit | Builds burst and damage value |
| Execute | Finisher | Cashes out combo pressure |
| Overdrive | Style surge | Makes the current route louder and faster |
