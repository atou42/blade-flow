# v0.2.20 数值读牌验收

日期：2026-05-08

本次修复目标是把武器、奖励、事件和结算里的模糊效果说明改成可读数值。玩家在做选择时应该能直接看到路线值、伤害变化、补牌冷却变化、Boss 出手提前、Boss 烙印、侦察、破势证据和专注回复。

实现内容：

- 武器选择改为具体数值说明。风暴太刀、镜扇、处刑者会显示开局路线值、伤害或保连收益，以及 Boss 获得的烙印。
- 奖励池和事件选择改为具体数值说明。遗物、契约、刻印、战斗证据、强化和休整都不再使用“更快”“更重”“更赚”这类模糊描述。
- 奖励说明新增统一数值渲染。正面收益数字使用青绿色，Boss 代价和烙印数字使用朱红色，侦察和证据类数字使用金色。
- 选择卡片下方新增效果标签。标签会从当前调配器参数计算补牌冷却降幅和伤害增量，避免界面写死后和调参结果脱节。
- 路线节点说明也改成 HP、伤害、抬手时间、Boss 压力和契约代价等具体数值。

验收结果：

- `node --check src/game.js` 通过。
- Playwright 手机宽度截图通过。武器选择页能看到 v0.2.20、三件武器的具体收益和 Boss 代价。
- Playwright 奖励面板截图通过。风格结算页能看到遗物、刻印和契约的路线值、伤害、补牌冷却和 Boss 出手提前。
- 截图产物：
  - `output/playwright/v0220-numeric-effects-start.png`
  - `output/playwright/v0220-numeric-effects-reward.png`

结论：v0.2.20 达到数值可读性验收标准。选择时不再只靠抽象文字理解效果，数字和颜色能直接告诉玩家这是收益、风险还是情报。
