# v0.2.21 稀有度印章验收

日期：2026-05-08

本次修复目标是让奖励稀有度不再只藏在说明文字里。奖励和事件选择需要在标题旁直接显示普通、稀有、史诗，并用颜色和点数辅助识别。

实现内容：

- 新增奖励稀有度印章。普通是凡字 1 点，稀有是青字 2 点，史诗是赤字 3 点。
- 奖励和事件选择卡会按稀有度改变边框。史诗奖励额外有朱红纸面压色。
- 效果说明行只保留类型和具体数值，稀有度从文字说明迁移到标题旁的视觉印章。

验收标准：

- 手机宽度下，风格结算面板里不读正文也能看出奖励稀有度。
- 稀有度印章不能挤掉奖励名称和数值说明。
- 普通、稀有、史诗在水墨背景上要有足够对比。
