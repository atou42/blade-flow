# v0.2.23 本地存档验收

日期：2026-05-08

本次修复目标是提供浏览器本地进度槽，方便测试不同路线，也方便继续往下玩当前局。

当前状态说明：

- 多关卡和局外强化还没有完整落地。现在线上仍是第一幕上行刀路切片。
- 本次先补本地存档能力，后续扩第二幕、第三幕和局外成长时可以沿用。

实现内容：

- HUD 新增存档入口。
- 浏览器本地提供 5 个存档槽。
- 每个槽可以保存当前局面、读取和删除。
- 存档内容包含当前房间、武器、手牌、补牌堆、奖励、路线烙印、Boss 状态、血量、连击、调配器参数和当前弹窗阶段。
- 存档结构损坏时显示错误，不直接清空或覆盖。

验收标准：

- 手机宽度下能打开本地存档面板。
- 空槽可以保存当前进度。
- 已有槽可以读取并回到对应战斗或奖励选择。
- 已有槽可以删除，删除后不会影响其他槽。
