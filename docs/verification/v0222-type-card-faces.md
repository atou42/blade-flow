# v0.2.22 类型牌面验收

日期：2026-05-08

本次修复目标是让奖励类型不再只靠文字区分。玩家应该能在奖励卡标题旁直接看出它是遗物、强化、刻印、契约、战斗证据还是休整。

实现内容：

- 新增类型印章。遗物是器，强化是斩，刻印是刻，契约是裂，证据是证，休整是息。
- 奖励卡按类型增加左侧色线。契约和证据额外使用不同纸面压色，避免只靠小标签识别。
- 稀有度印章继续保留。类型印章和稀有度印章分开显示。

验收标准：

- 手机宽度下，奖励卡标题旁能同时看到类型和稀有度。
- 不读正文也能区分遗物、强化、刻印、契约、证据、休整。
- 类型印章不能挤掉奖励名称、稀有度和数值说明。
