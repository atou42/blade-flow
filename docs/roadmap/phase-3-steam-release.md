# Phase 3: Steam Release Target

## Goal

Reach a polished Steam-ready release candidate.

## Scope

Complete the three-act run structure.

Add enough enemy and boss variety to support repeated runs.

Polish portrait UI, gesture feel, combat readability, hit feedback, audio escalation, and route-state presentation.

Add settings for input buffer feel, accessibility, readable text, and mobile portrait constraints.

Add Steam-facing features such as achievements, daily challenge, leaderboards if appropriate, cloud save if supported, and a clean first-run tutorial.

## Success Criteria

The first ten minutes sell the core fantasy.

The first successful run feels complete.

The tenth run feels different from the third run.

High-skill play looks visibly better than beginner play.

The game can be described clearly as a portrait roguelike combo card action game.
