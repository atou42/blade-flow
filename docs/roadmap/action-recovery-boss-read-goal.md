# Action Recovery Boss Read Goal

日期：2026-05-10

实现 Blade Flow 下一版动作后摇与 Boss 读招切片，目标是让左划从免费保险变成读对才高收益的招架动作，并让玩家通过 Boss 动作、真确认音效、卡牌短亮和错读反馈快速学会正确出法；以 `docs/design/action-recovery-boss-read-spec.md` 和 `docs/design/action-recovery-audio-spec.md` 为行为与声音来源，接入已生成的 15 个动作后摇/读招/教学 SFX，保持现有 BGM、SFX 静音、Web Audio 预解码、手机底部安全距离、R2 美术、存档、调配器、训练/日课/三幕流程和 `games.atou.cc` 部署路径不退化；完成后，一幕普通战、镜侍精英和风暴队长必须能证明连续左划不再稳定打断所有 Boss 动作，快刀真确认左划能打断并缩短后摇，假抬手第一次红核左划会空闪并加长后摇，慢刀普通左划不能完整重置 Boss、下划中后段破势才打断，地裂抓取会惩罚站桩重招；新增后摇必须有可感知但不拖泥带水的手感，收招末尾 160ms 输入缓存可用，收招前段乱滑不会排成长队；新增音效必须开战前预解码，手势期间不发生首次资源请求、长任务或音频错误；用本地和线上手机视口、调试探针、连续左划压测、Boss 指定招式复测、控制台检查和验收文档证明这些行为成立，部署到 `games.atou.cc/combo-card-roguelike/versions/a/` 后才允许标记完成；如果发现素材缺失、浏览器音频限制、性能预算或交互手感阻止达标，必须明确暴露阻塞，不能用吞错、延迟播放或只调高数值假装解决。
