# Phase 0: Combat Prototype

## Goal

Prove the core combat feel.

The player should be able to read four cards, tap or flick a card, see a clear action, receive a replacement card, and feel pressure to keep the combo alive.

## Scope

Use the twelve-card blade-dance starter deck.

Implement tap plus four directional variants for every card.

Use one normal enemy and one small boss.

Use one default equipment identity, preferably Storm Katana.

Use a combo meter, route state display, card replacement, and basic enemy pressure.

## Success Criteria

A new player can survive by tapping.

A practiced player can play faster, use flick variants, maintain longer combos, and trigger route states.

Dropping combo feels painful enough to matter, but not so punishing that the player stops experimenting.

## Explicit Non-Goals

No full three-act run.

No large reward pool.

No long-term progression.

No complex equipment inventory.
