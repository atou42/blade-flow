# Phase 1：上行刀路肉鸽切片

## 目标

证明当前战斗可以支撑一局小型肉鸽，并证明路线选择不是普通技能升级，而是会改变下一场战斗的手感、读招压力和 Boss 行为。

## 范围

Phase 1 先不做完整三幕。先做一幕七到八个节点，六到八分钟一局。地图是竖屏向上的刀痕路线，玩家从下方逼近本幕 Boss。每次只展示未来两层，每层给两条路线。

节点包含普通战、精英、商店、锻造、侦察、事件、Boss 预演和最终 Boss。普通战给卡牌、普通遗物或改牌机会。精英给强遗物、装备调校或契约，同时增加明确风险。商店卖卡牌、遗物、一次性印记、装备刻印和 Boss 情报。锻造改变卡牌方向倾向或补牌节奏，不做纯数值升级。侦察展示 Boss 的一个抬手。Boss 预演给短时间残影练习。事件先做风险交易和路线突变。

首版只做三条流派。追击路线用风暴太刀，强调右划追身和快速补牌，但会引出 Boss 后撤横切。闪反路线用镜扇，强调左划读抬手和残影反打，但会引出 Boss 假抬手。爆发路线用处刑者，强调破势和 Execute 收尾，但会引出 Boss 地裂抓取或处决锁窗。

遗物先做六个，每条路线两个。契约先做三个，分别服务追击、闪反和爆发。特殊规则先做慢炉、裂手、红炉和镜廊。Boss 情报先做三条，对应快刀、慢刀和假动作。

## 奖励规则

连击决定奖励数量和地图选择宽度。读招决定 Boss 情报和图鉴进度。破势决定素材品质和 Boss 支线。乱打也能通关，但只能拿普通奖励。读对抬手、危险窗口贪刀成功、破势后收尾，才会出现装备残件、Boss 遗物或强契约。

装备是开局契约，不是装备栏。开局只选一件主装备。精英后可以拿装备调校，Act Boss 后才允许装备进化或诅咒装备。

## 验收标准

连续玩三局，三局手感必须能被玩家说出来。一局像高速贴身追刀，一局像等 Boss 出手再反打，一局像冻结爆点后赌命处决。

玩家进入最终 Boss 前，必须能看到自己选择留下的路线烙印。进入战斗后，Boss 第一轮动作就要体现烙印影响。

地图上至少出现一次不是技能升级的选择。这个选择必须影响下一场战斗的手牌节奏、Boss 抬手或角色动作。

空等手牌、同方向乱冲、无脑连击都不能比读招连击更赚。谨慎等待可以活下来，但拿不到高价值奖励。
